# Contributing to Antigravity Upgrade

Thank you for your interest in contributing! We welcome bug fixes, improvements, and feature suggestions.

## Guidelines

1. **Reporting Issues:**
   * Search existing issues to avoid duplicates.
   * Provide reproduction steps, OS version, Antigravity version, and non-sensitive logs.
   * Do not include private tokens, API keys, or personal account credentials in reports.

2. **Submitting Changes:**
   * Fork the repository and create a feature branch.
   * Ensure tests pass cleanly: `npm test`.
   * Keep commits focused, well-documented, and atomic.
